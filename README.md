### RXos / RXnm

An experimental neuromorphic operating-system and networking ecosystem.

RXos and RXnm explore a computing architecture with its own communication protocol and network model, designed without depending on conventional IP addressing, TCP transport or traditional DNS infrastructure.

```text
Languages: Rust · C · Python · Assembly
Areas: operating systems · networking · security · neuromorphic computing
```

The project investigates how operating systems, identity, networking and low-level applications could operate as a single integrated environment.

---

### Roxonium

A low-level programming language being designed from scratch for RXos.

Roxonium combines a simple and readable syntax inspired by Python with the control required for systems programming and native RXos application development.

```python
system boot:
    initialize network
    establish identity
    run application
```

Its objective is to make low-level development more accessible without hiding the underlying system.
